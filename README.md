# Python – Datenverarbeitung und Objektorientierung

Python-Programme zum Einlesen von JSON- und XML-Dateien und zur objektorientierten Modellierung. Entstanden im Lernfeld LF08 „Daten systemübergreifend bereitstellen" der Umschulung zur Fachinformatikerin für Systemintegration (GFN).

## Inhalt

| Ordner / Datei | Thema |
|---|---|
| `Werkstatt.py` | OOP-Grundprinzipien: Abstraktion, Vererbung, Kapselung, Polymorphie |
| `json-xml-uebungen/` | JSON- und XML-Dateien einlesen und auswerten |
| `gebaeudeverwaltung/` | Vererbung am Beispiel Gebäude, Lagerhalle, Wohnhaus |
| `musikinstrumente-v1/` | Klassenmodell Musikinstrumente, Version 1 |
| `musikinstrumente-v2/` | Klassenmodell Musikinstrumente, Version 2 (Gitarre, Saxophon) |

## Technologien

Python 3, JSON, XML, objektorientierte Programmierung
